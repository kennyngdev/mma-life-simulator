# 大俠模擬器

一個獨立的晚明武俠人生模擬器。玩家從一名普通少年開始，抽取可重現的出身、天賦與麻煩，選擇門派，經歷十六回合的成長、關係與戰鬥，最後得到一段短傳記。

## 開發

- `pnpm dev`：在固定的 `3010` 埠啟動玩家測試網站
- `pnpm dev:agent`：在 `3011` 埠啟動代理預覽；代理不得佔用 `3010`
- `pnpm test`：驗證人生與戰鬥的決定性規則
- `pnpm lint`：檢查程式碼
- `pnpm build`：建立部署版本

## 專案結構

- `app/page.tsx`：完整遊戲介面與本機存檔流程
- `app/life-engine.ts`：人生階段、種子、關係、成長、遭遇與結局
- `app/battle/`：純函式、可重播的戰鬥引擎
- `app/game.module.css`：單一手機優先遊戲畫面
- `docs/`：從原專案提煉、只屬於本遊戲的設計原則
